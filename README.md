Overview

Projects Included
1. College Information Website — Case 2
Website name: NRI University College Information Website

Purpose: To provide college information in one place for students, parents, and visitors.

Sections:
- Home
- About
- Courses
- Facilities
- Placements
- College Tour
- Celebrations
- Contact Us
Technologies: HTML, CSS, JavaScript

Summary: The website brings together college details, academic programs, facilities, placement information, and campus activities.
2. Doctor Appointment Website — Case 12
Website name: MediCare Clinic

Purpose: To help patients find doctors and request appointments.

Sections:
- Home
- Services
- Doctors
- Appointment
- About
- Contact
Features:
- Displays medical services.
- Shows doctors' names and specializations.
- Allows patients to enter details, select a doctor, and choose a date and time.
Technologies: The report identifies HTML and CSS and mentions interactive features.

Summary: The website helps patients explore medical services, find doctors, and request appointments through a user-friendly interface.
3. Restaurant and Cafe Website — Case 20
Website name: Velvet Brew

Purpose: To present the restaurant, display menu items, and let customers submit table reservation requests.

Features:
- Home section with a restaurant introduction and image.
- Navigation bar for moving between sections.
- Menu with food images, descriptions, prices, and “Choose” buttons.
- Reservation form for name, email, date, time, and number of guests.
- Cream and brown colour scheme.
Technologies: HTML, CSS, JavaScript

Summary: The website provides a user-friendly way for customers to explore menu items and submit reservation requests.
Requirements
- A web browser to view the websites.
- A code editor to edit HTML, CSS, and JavaScript.
- The HTML, CSS, JavaScript, and image files used by each project.
How to Run
1. Locate the main HTML file for the website.
2. Keep linked CSS, JavaScript, and image files in their expected locations.
3. Open the HTML file in a web browser, or use a local development server if required.
4. Navigate through the sections and test the interface elements.
